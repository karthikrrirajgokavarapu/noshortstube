NoShortsTube is an Android learning project that wraps YouTube’s mobile site and experiments with a less distracting viewing experience.

APK coming soonExplore the code
The APK download will be enabled after a build is published in GitHub Releases.
01 / FOCUS

Reduce Shorts clutter

Best-effort filtering of recognizable Shorts elements in the mobile page.

02 / CONTROL

Native fullscreen

React Native handles fullscreen state, Android Back, and screen orientation.

03 / OPEN

Built to learn

A small Expo and WebView project with its page helper kept separate from the app shell.

Project notes

This is an independent prototype. YouTube can change its page structure, so filtering may stop working. It does not provide video downloads, background playback, or guaranteed ad removal. Use YouTube’s official features for supported offline viewing.
